Free helper for the Nudge extension

Connect Nudge to Claude

Nudge needs one small app on your computer to use your own Claude subscription. Download it, open it, click Install. That's it.

Download for Mac Download for Windows

If Windows shows Windows protected your PC, click More info, then Run anyway. It appears for new apps until Windows recognises them.

This Mac has an Intel chip. The helper runs on Apple silicon Macs (M1 and later) for now.

Needs a Claude Pro or Max subscription and Chrome, Edge, Brave, Arc, Vivaldi, Opera or Helium.

How it works

About a minute, no settings to change.

1

Download

Use the button above. It picks the right file for your computer.

2

Open it and click Install

On a Mac, open Nudge-Helper.pkg. On Windows, open Nudge-Helper-Setup.exe. No password needed.

3

Back to your browser

Open Nudge. It connects by itself. The first time, click Sign in with Claude and approve on claude.ai.

Linux, manual install and removing the helper

Linux

Download nudge-helper-linux-x64.zip, unzip it somewhere you'll keep it, and run ./install.sh in that folder. To remove it, run ./uninstall.sh.

Manual install (zip)

Prefer a folder you control? Use the macOS zip or Windows zip: unzip it, then run ./install.sh (Mac) or double-click install.cmd (Windows).

Removing the helper

Windows: Settings, Apps, Nudge Helper, Uninstall.

Mac: in Terminal, run ~/Library/Application\ Support/Nudge/helper/uninstall.sh, then delete that Nudge folder.

Safe to install

The Mac installer is signed by the developer and approved by Apple. Both installers set things up for your user only and never ask for an admin password.

Your own Claude

The helper runs Claude Code signed in with your account. Nothing goes through the developer. Read the privacy policy.

Need help?

Email baradesignlab@gmail.com. The helper keeps a log at ~/.nudge/host.log (timings only, never your data).
