The Nudge helper

Nudge uses a small app on your computer to reach your own Claude. The extension offers it when you first open it, so most people never need this page. If you'd rather install it first, pick your computer:

Mac

Apple silicon (M1 and later). Open Nudge-Helper.pkg and click Install.

Download for Mac

Windows

Windows 10 or 11. Open Nudge-Helper-Setup.exe, then Next and Finish. If Windows says it protected your PC, click More info, then Run anyway.

Download for Windows

LinuxBeta

x64. Unzip it somewhere you'll keep it and run ./install.sh in that folder.

Download for Linux
Manual install and removing the helper

Manual install (zip)

Prefer a folder you control? Use the macOS zip or Windows zip: unzip it, then run ./install.sh (Mac) or double-click install.cmd (Windows).

Removing the helper

Windows: Settings, Apps, Nudge Helper, Uninstall.

Mac: in Terminal, run ~/Library/Application\ Support/Nudge/helper/uninstall.sh, then delete that Nudge folder.

Linux: run ./uninstall.sh in the helper's folder, then delete the folder.

Safe to install

The Mac installer is signed by the developer and approved by Apple. Both installers set things up for your user only and never ask for an admin password.

Your own Claude

The helper runs Claude Code signed in with your account. Nothing goes through the developer. Read the privacy policy.
