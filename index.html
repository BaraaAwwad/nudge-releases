Nudge helper

A small app that connects the Nudge browser extension to your own Claude, running on your computer. Your forms and memory never touch a Nudge server.

Install

Unzip the download somewhere you'll keep it, then run the installer. It sets things up for your user only, with no admin rights, and opens claude.ai if you need to sign in: approve, copy the code, and paste it into the installer window.

Windows

  1. Unzip nudge-helper-windows-x64.zip.
  2. Double-click install.cmd in the folder.
  3. Open the Nudge extension. It should say Connected.
Where it goes: the helper runs from the folder you unzipped. The installer writes a small manifest to %LOCALAPPDATA%\Nudge and registers it with your browsers (per-user registry).

Uninstall: double-click uninstall.cmd, then delete the folder.

macOS

  1. Unzip nudge-helper-macos-arm64.zip.
  2. Open Terminal in that folder and run ./install.sh
  3. Open the Nudge extension. It should say Connected.
Where it goes: the helper runs from the folder you unzipped. Browser manifests go in ~/Library/Application Support/<browser>/NativeMessagingHosts. If macOS blocks it, run xattr -dr com.apple.quarantine . in the folder first.

Uninstall: run ./uninstall.sh, then delete the folder.

Linux

  1. Unzip nudge-helper-linux-x64.zip.
  2. Open a terminal in that folder and run ./install.sh
  3. Open the Nudge extension. It should say Connected.
Where it goes: the helper runs from the folder you unzipped. Browser manifests go in ~/.config/<browser>/NativeMessagingHosts.

Uninstall: run ./uninstall.sh, then delete the folder.

Keep the folder

Your browser starts the helper from where you unzipped it. If you move the folder, run the installer again.

Your own Claude

The helper runs Claude Code signed in with your account. Nothing goes through the developer. Read the privacy policy.

Need help?

Email baradesignlab@gmail.com. The helper keeps a log at ~/.nudge/host.log (timings only, never your data).
